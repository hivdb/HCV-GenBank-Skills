# HCV reference sequences

This directory contains HCV genotype and subtype amino-acid reference FASTAs, Comet consensus FASTAs, and reference-to-consensus comparison CSVs for NS3, NS5A_NTD, and NS5B.

## Subtype references

The subtype reference names and included subtypes follow the ICTV **Table 1 – Confirmed HCV genotypes/subtypes (January 2026)**:

<https://ictv.global/sg_wiki/flaviviridae/hepacivirus/table1>

The January 2026 update adds subtype references for 4a (`Y11604`), 5b (`PQ899568`), 6b (`D84262`), and 7a (`EF108306`), and uses the ICTV subtype names `4w` and `6xa`.

NS5A references cover the N-terminal domain only (NS5A_NTD; 213 amino acids).
