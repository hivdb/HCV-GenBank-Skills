## General method

The analysis identifies amino-acid covariation separately within the NS3,
NS5A, and NS5B proteins, and compares sequences only within the same HCV
subtype. For each position pair, sequences with a missing amino-acid call at
either position are excluded. A subtype contributes only when it has at least
**20 paired sequences** (default `--min-n 20`) and at least **3 calls outside
the modal amino acid at each position** (default `--min-minor 3`).

Within every eligible subtype, mutual information (MI) quantifies how much
knowing the amino acid at one position predicts the amino acid at the other.
Subtype-specific MI values are combined in two ways: a sequence-weighted
summary, in which larger subtypes contribute more, and a subtype-balanced
summary, in which every eligible subtype contributes equally. The primary
effect size is adjusted MI: observed MI minus mean permuted MI.

Statistical significance is assessed using **999 within-subtype permutations**
by default (default `--permutations 999`; default random seed
`--seed 20260923`). In each permutation, one position is shuffled within
subtype, preserving its amino-acid frequencies but breaking its observed
pairing with the other position. Permutation P values are adjusted with the
Benjamini–Hochberg false-discovery-rate procedure separately for each scan
family (RAS–RAS or RAS–non-RAS) and each weighting method. Results with
**q ≤ 0.05** are considered significant by default (default `--alpha 0.05`).

For significant pairs, the analysis reports contributing subtype sample sizes,
MI statistics, and the amino-acid combinations behind the association. A
combination is included in the detailed output only when its observed count is
at least **3** (default `--min-combination-count 3`). Results are also
recalculated after exact-profile deduplication within subtype: one copy of each
fully observed identical profile is retained, while incomplete profiles are
kept. An optional near-duplicate sensitivity analysis can instead cluster
profiles at a user-specified maximum number of differences; it is off by
default.

The results identify statistical amino-acid associations, not necessarily
direct biological interactions. Subtype stratification limits confounding from
subtype-specific amino-acid frequencies, but shared ancestry, geography, and
sampling structure within subtype can still contribute to covariation.

## Q-value calculation

We calculate q values with the **Benjamini–Hochberg (BH) false-discovery-rate procedure**.

1. For each position pair, we first calculate a permutation P value by shuffling one position **within subtype**. With `B` shuffles, the P value is
   `p = (1 + number of shuffled MI values >= observed MI) / (B + 1)`.
2. Within each scan family (RAS–RAS or RAS–non-RAS), we collect the eligible pairs' P values separately for each weighting method: `sequence_weighted` and `subtype_balanced`.
3. For each such group, we sort P values from smallest to largest. For the P value at rank `i` among `m` tested pairs, the BH value is `p_i × m / i`.
4. Moving from the largest rank back to the smallest, we replace each value with the cumulative minimum (capped at 1). The resulting monotone BH-adjusted values are reported as `q_value`.

Thus, q values control the false discovery rate within a scan family and weighting method; they are not calculated across different weighting methods or across RAS–RAS and RAS–non-RAS scans. A pair is treated as significant at the default threshold when `q_value <= 0.05`.
