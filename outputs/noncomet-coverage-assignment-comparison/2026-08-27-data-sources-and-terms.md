# 2026-08-27: comparison data sources and terms

## Purpose

This folder compares two independent genotype/subtype call sources for NS3, NS5A, and NS5B. Accessions are matched after removing a version suffix such as `.1`.

## `from_db`

`from_db` means the all-sequence non-COMET coverage tables in:

```text
HCVData/HCV-all-seq-subtype/
  NS3_AllSeq_NonComet_Coverage.csv
  NS5A_AllSeq_NonComet_Coverage.csv
  NS5B_AllSeq_NonComet_Coverage.csv
```

These tables are generated by:

```text
Preprocess/Ref/hcv-all-seq-noncomet-coverage-audit/scripts/audit_all_fasta_coverage.py
```

The audit starts from `HCVData/HCV-all-seq-subtype/all.fasta`, calls the folder BLAST assignment workflow, and adds gene-reference coverage information. Its genotype and subtype fields are named `ClosestGenotype` and `ClosestSubtype`.

## `from_fasta`

`from_fasta` means the gene-specific assignments in:

```text
outputs/folder_assignments/
  NS3_assignments.csv
  NS5A_assignments.csv
  NS5B_assignments.csv
```

They are generated directly from an input folder of `.fa`, `.fasta`, or `.fna` files by:

```text
hcv-workflow/hcv-folder-genotype-subtype-assignment/scripts/assign_folder_genotype_subtype.py
```

For each detected gene, this workflow uses `blastn` first for genotype, then for the nearest subtype within that genotype. Its genotype and subtype fields are named `genotype` and `subtype`.

## Output terms

| Term | Meaning |
| --- | --- |
| `FromDb*` | Value from the all-sequence non-COMET coverage table. |
| `FromFasta*` | Value from the folder FASTA assignment CSV. |
| `SharedAccessions` | Accessions present in both sources. |
| `OnlyInFromDb` | Accessions in the coverage table but absent from the folder assignment file. |
| `OnlyInFromFasta` | Accessions in the folder assignment file but absent from the coverage table. |
| `GenotypeDifferences` | Shared accessions with different genotype calls. |
| `SubtypeDifferences` | Shared accessions with different subtype calls, including a blank call on one side. |
| `DifferenceType` | Whether a differing row disagrees for `GENOTYPE`, `SUBTYPE`, or `BOTH`. |

The `*_only_in_from_db.csv` and `*_only_in_from_fasta.csv` files list the individual accessions behind the two missing-accession counts.
